# About WeChatQRCode Models
These models are used by `traitly.utils.label.detect_qr` for QR code detection.

## Source
Models from [WeChatCV](https://github.com/WeChatCV/opencv_3rdparty/tree/wechat_qrcode),
contributed to [OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/qrcode_wechatqrcode)
by the WeChat Computer Vision Team.
