# CLI: Command-Line Interface

Traitly includes a command-line interface that allows running analyses directly from the terminal, without writing Python code. It is especially useful for processing batches of images on servers or computing environments where notebooks or interactive scripts are not available.

---

## Basic usage

```bash
traitly --fruit_internal -i PATH [-o PATH] [--json PATH] [--num_cores N]
traitly --fruit_external -i PATH [-o PATH] [--json PATH] [--num_cores N]
```

The input (`-i`) can be a single image or a folder with multiple images. In both cases, the CLI automatically delegates to the corresponding method (`process_single_file` or `analyze_folder`).

!!! tip "A JSON file is required to configure the analysis"

    **All analysis configuration must be passed through a `.json` file with `--json`.**

    There are two ways to obtain one:

    **Option 1 – From Python:**

    1. Adjust the parameters on a representative image
    2. Save the configuration with `analyzer.save_parameters()`
    3. Pass the generated `.json` file with `--json` in the terminal

    **Option 2 – From a template:**

    Copy the base file, modify the parameters you need in any text editor, and save it as `.json`. Then pass it with `--json`.

    [:octicons-file-code-24: View JSON template](../assets/templates/parameters_template.json)

    To learn what each parameter does, see the documentation for [`FruitInternalAnalyzer`](internal_class.md) or [`FruitExternalAnalyzer`](external_class.md).

## Arguments

| Argument | Type | Default | Description |
|-----------|------|---------|-------------|
| `--fruit_internal` | `flag` | — | Runs internal structure analysis (`FruitInternalAnalyzer`) |
| `--fruit_external` | `flag` | — | Runs external appearance analysis (`FruitExternalAnalyzer`) |
| `-i`, `--input` | `str` | — | Path to the image or folder to analyze (**required**) |
| `-o`, `--output` | `str` | `None` | Output directory; if `None`, a `Results/` subfolder is created inside the input folder |
| `--json` | `str` | `None` | Path to the `.json` parameters file generated by `save_parameters()` |
| `--num_cores` | `int` | `1` | Number of CPU cores for parallel processing |
| `--no_morphology` | `flag` | — | Skips morphology analysis |
| `--no_color` | `flag` | — | Skips color analysis |
| `--version` | `flag` | — | Displays the installed version of Traitly |
| `--help` | `flag` | — | Displays available arguments and usage examples |

!!! warning "Important"
    `--fruit_internal` and `--fruit_external` are mutually exclusive — only one can be used per call.

<br>

## Examples

**Internal analysis on a folder, using saved parameters:**
```bash
traitly --fruit_internal -i data/fruit_slices/ --json config.json
```

**External analysis with custom output and parallel processing:**
```bash
traitly --fruit_external -i data/whole_fruits/ -o results/ --num_cores 4
```

**Analysis on a single image:**
```bash
traitly --fruit_internal -i data/image_001.jpg --json config.json
```

**Morphology only, skip color:**
```bash
traitly --fruit_internal -i data/slices/ --json config.json --no_color
```

**Check installed version:**
```bash
traitly --version
```

**View available arguments:**
```bash
traitly --help
```

<br>

---

## Outputs

The CLI generates the same files as `analyze_folder()` from Python:

| File | Description |
|---------|-------------|
| `morphology_results.csv` | Morphological metrics for all detected fruits |
| `color_results.csv` | Color metrics for all detected fruits |
| `session_report.txt` | Session summary: images processed, fruits detected, processing times, and parameters used |
| `error_report.txt` | Per-image error detail (only generated if any image failed) |
| Annotated images | One annotated image per processed image |

All files are saved to the directory specified with `-o`, or to a `Results/` subfolder inside the input folder if not specified.
